Frequently Asked Questions

How does StartFlow work?

StartFlow acts as a unified API gateway that routes your requests to the best available AI model based on your requirements, cost constraints, and performance needs.

Is there a free tier?

Yes! StartFlow offers a generous free tier with 100K tokens per month. Perfect for testing and small projects.

How do I get started?

Simply sign up for an account, get your API key, and start making requests. Our documentation has quick-start guides for all major languages.

Can I use my existing OpenAI code?

Absolutely! StartFlow is fully compatible with the OpenAI API format. Just change the base URL and you're good to go.
